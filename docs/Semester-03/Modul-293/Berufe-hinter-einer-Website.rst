Berufe hinter einer Website
===========================

Einleitung
-----------

Bei der Erstellung einer professionellen Website arbeiten verschiedene Berufsleute zusammen.

Ein Vergleich aus dem Alltag:

Eine Pizzeria besteht nicht nur aus dem Pizzaiolo. Es gibt auch Mitarbeitende im Service, Köche für weitere Gerichte, Reinigungspersonal und eine Person, welche die Verantwortung für den gesamten Betrieb übernimmt.

Ähnlich verhält es sich bei der Entwicklung professioneller Websites. Auch dort arbeiten verschiedene Fachpersonen mit unterschiedlichen Aufgaben und Kompetenzen zusammen.

.. important::

   Eine professionelle Website wird häufig von mehreren Spezialisten entwickelt und betreut.

Frontend-Entwicklerinnen / Webdesigner
--------------------------------------

Frontend-Entwicklerinnen und Webdesigner kümmern sich hauptsächlich um das sichtbare Erscheinungsbild einer Website.

Aufgaben:

- Typografie
- Layout
- Farbgestaltung
- Grafische Gestaltung
- Benutzerinteraktion
- Seitenplanung

Kompetenzen:

- HTML
- CSS
- Schriftarten
- Photoshop
- Adobe Illustrator
- Adobe XD
- Figma

User Experience Designer
------------------------

Der Schwerpunkt liegt auf dem menschlichen Verhalten und dessen Interaktion mit Webseiten.

Ziel:

- Verbesserung der Benutzerführung
- Optimierung der Nutzererfahrung

Kompetenzen:

- HTML
- CSS
- Adobe XD
- Figma

.. note::

   User Experience Designer konzentrieren sich hauptsächlich darauf, wie Benutzer eine Website wahrnehmen und bedienen.

Interaktive Media Designer EFZ
------------------------------

Dieser Beruf kann in der Schweiz als EFZ-Ausbildung erlernt werden.

Die Schwerpunkte liegen bei:

- Audio
- Video
- 3D-Animationen
- Interaktiven digitalen Inhalten

Kompetenzen:

- HTML
- CSS
- JavaScript
- JavaScript-Frameworks
- Adobe XD
- Bildbearbeitung
- Videobearbeitung
- Audiobearbeitung

.. tip::

   Die Ausbildung dauert vier Jahre, da das Berufsfeld sehr umfangreich ist.

CMS-Spezialisten
----------------

Grosse Content-Management-Systeme (CMS) können sehr komplex sein.

Beispiele:

- WordPress
- Joomla
- Typo3
- Drupal

Aufgaben:

- Wartung
- Unterhalt
- Kundenspezifische Anpassungen
- Erweiterungen erstellen
- Datenbanken verwalten

Kompetenzen:

- HTML
- CSS
- JavaScript
- CMS-spezifische Kenntnisse
- PHP

Backend-Entwicklerinnen
-----------------------

Das Backend umfasst alle Bereiche einer Website, die nicht direkt sichtbar sind.

Dazu gehören:

- Serverseitige Programme
- Datenverarbeitung
- Datenbanken

Kompetenzen:

- PHP
- Python
- Ruby
- C#
- Java
- Node.js
- Apache
- Nginx
- SQL
- JSON
- MongoDB

.. warning::

   Das Backend ist für Benutzer normalerweise nicht sichtbar, übernimmt aber die Verarbeitung und Speicherung von Daten.

Full Stack
----------

Personen, welche sowohl Frontend als auch Backend beherrschen, werden als Full-Stack-Entwicklerinnen bezeichnet.

Eigenschaften:

- Kenntnisse im Frontend
- Kenntnisse im Backend
- Sehr vielseitig einsetzbar

.. important::

   Full-Stack-Entwicklerinnen gehören zu den gefragtesten Fachpersonen im Webbereich.

Zusammenfassung
---------------

Bei professionellen Websites arbeiten verschiedene Fachpersonen zusammen.

Dazu gehören:

- Frontend-Entwicklerinnen
- Webdesigner
- User Experience Designer
- Interaktive Media Designer
- CMS-Spezialisten
- Backend-Entwicklerinnen
- Full-Stack-Entwicklerinnen

Jeder dieser Berufe besitzt eigene Schwerpunkte, Aufgaben und Technologien.
