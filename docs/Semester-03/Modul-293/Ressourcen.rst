In diesem Kapitel werden alle wichtigen Lernquellen des Moduls 293 gesammelt.

Smartlearn
~~~~~~~~~~

Zentrale Lernplattform des Moduls.

Verwendete Themen:

- Berufe hinter einer Website
- Entwicklungsumgebung
- HTTP-Protokoll
- HTML
- CSS
- DevTools
- Formulare
- JavaScript
- Website veröffentlichen

W3Schools
~~~~~~~~~

W3Schools dient im Modul regelmässig als Nachschlagewerk.

Behandelte Themen:

- HTML
- CSS

- HTML DOM
- JavaScript
