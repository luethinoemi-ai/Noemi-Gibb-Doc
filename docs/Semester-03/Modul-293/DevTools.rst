DevTools
========

Lernziele
~~~~~~~~~

.. important::

   - Ich kenne die DevTools.
   - Ich kann eine Webseite mit den DevTools untersuchen.

Einführung
~~~~~~~~~~

Bevor mit weiterer Theorie gearbeitet wird, lohnt es sich, ein wichtiges Werkzeug kennenzulernen:

**Browser DevTools**

Die DevTools sind in modernen Browsern vorhanden und helfen dabei, Webseiten genauer zu untersuchen.

.. note::

   DevTools stehen in modernen Browsern zur Verfügung.

Nutzen der DevTools
~~~~~~~~~~~~~~~~~~~

Mit den DevTools kann untersucht werden:

- Wie eine Webseite aufgebaut ist
- Wie HTML verwendet wird
- Wie CSS eingesetzt wird
- Wie JavaScript eingebunden wird

Dadurch kann nachvollzogen werden, wie bestimmte Funktionen oder Darstellungen umgesetzt wurden.

.. tip::

   Wenn dir eine Webseite gefällt, kannst du mit den DevTools untersuchen, wie sie aufgebaut wurde.

Lernen durch Beobachten
~~~~~~~~~~~~~~~~~~~~~~~

Die DevTools ermöglichen es, von bestehenden Webseiten zu lernen.

Vorgehen:

.. code-block:: text

   Webseite öffnen
          │
          ▼
      DevTools öffnen
          │
          ▼
   HTML untersuchen
          │
          ▼
    CSS untersuchen
          │
          ▼
   Aufbau verstehen

.. important::

   Das Untersuchen von Webseiten ist eine gute Möglichkeit, um neue Techniken kennenzulernen.

Urheberrecht und Inhalte
~~~~~~~~~~~~~~~~~~~~~~~~

Beim Untersuchen von Webseiten muss zwischen dem Lernen und dem Kopieren von Inhalten unterschieden werden.

.. warning::

   Bilder und Inhalte dürfen nicht einfach für eigene Zwecke kopiert werden.

Dazu gehören beispielsweise:

- Bilder
- Grafiken
- Texte
- Weitere Inhalte einer Webseite

Code bei Webseiten
~~~~~~~~~~~~~~~~~~

Bei Webseiten verhält sich die Situation beim Quellcode etwas anders.

Smartlearn beschreibt, dass der Fall bei Webseiten nicht eindeutig ist.

Es ist häufig schwierig festzustellen:

- Ob ein Code komplett selbst entwickelt wurde
- Ob einzelne Bereiche übernommen wurden
- Ob sich Teile an anderen Webseiten orientieren

Viele Webentwickler schauen bestehende Webseiten an und übernehmen Ideen oder Techniken für eigene Projekte.

.. note::

   Das Analysieren von HTML-, CSS- und JavaScript-Code gehört zur normalen Arbeit vieler Webentwickler.

Lernen mit DevTools
~~~~~~~~~~~~~~~~~~~

Beim Surfen im Internet können interessante Webseiten untersucht werden.

Dabei lassen sich viele Dinge lernen:

- Aufbau einer Webseite
- Struktur des HTML-Codes
- Verwendung von CSS
- Einsatz von JavaScript

.. tip::

   Nutze die DevTools regelmässig, wenn du auf interessante Webseiten triffst.

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Die DevTools ermöglichen:

   - Webseiten zu untersuchen
   - HTML zu analysieren
   - CSS zu analysieren
   - JavaScript zu analysieren
   - Von bestehenden Webseiten zu lernen

.. warning::

   Inhalte wie Bilder und Texte dürfen nicht einfach übernommen werden.

Prüfungswissen
~~~~~~~~~~~~~~

.. dropdown:: Wozu dienen die DevTools?

   Die DevTools dienen dazu, Webseiten zu untersuchen und deren Aufbau zu analysieren.

.. dropdown:: Was kann mit DevTools untersucht werden?

   HTML, CSS und JavaScript.

.. dropdown:: Darf man Inhalte einer Webseite einfach kopieren?

   Nein. Bilder und Inhalte dürfen nicht einfach für eigene Zwecke übernommen werden.

.. dropdown:: Warum sind DevTools hilfreich?

   Sie helfen dabei zu verstehen, wie Webseiten aufgebaut und programmiert wurden.
