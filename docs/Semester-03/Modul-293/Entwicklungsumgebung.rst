Entwicklungsumgebung
====================

Lernziele
---------

.. important::

   - Ich kenne eine geeignete Entwicklungsumgebung und kann diese einsetzen.
   - Ich kann meine Ergebnisse in der Liveserver-Ansicht ansehen.

Visual Studio Code
------------------

Bevor mit der Entwicklung der ersten Website begonnen wird, sollte eine geeignete Entwicklungsumgebung eingerichtet werden.

Für dieses Modul wird empfohlen, mit **Visual Studio Code** zu arbeiten.

.. note::

   Es darf grundsätzlich eine beliebige Entwicklungsumgebung verwendet werden.

Warum Visual Studio Code?
-------------------------

Visual Studio Code besitzt einen praktischen **Liveserver**.

Mit dem Liveserver können Änderungen an einer Website sehr schnell betrachtet werden, ohne die Seite jedes Mal manuell neu öffnen zu müssen.

.. tip::

   Der Liveserver hilft dabei, die eigenen Ergebnisse sofort zu überprüfen.
