Einführung OOP
==============

Was ist OOP?
~~~~~~~~~~~~

OOP steht für:

.. code-block:: text

   Objektorientierte Programmierung

Bei der OOP werden Programme mit Klassen und Objekten aufgebaut.

Grundbegriffe
~~~~~~~~~~~~~

Klasse
^^^^^^

Eine Klasse ist ein Bauplan.

Objekt
^^^^^^

Ein Objekt ist eine Instanz einer Klasse.

Attribut
^^^^^^^^^

Ein Attribut speichert Informationen.

Methode
^^^^^^^

Eine Methode beschreibt eine Fähigkeit eines Objekts.

Beispiel
~~~~~~~~

.. code-block:: text

   Klasse = Auto

   Objekt = Mein roter VW Golf

   Attribute:
   - Farbe
   - PS

   Methoden:
   - fahren()
   - bremsen()

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Klasse = Bauplan

   Objekt = Instanz

   Attribut = Eigenschaft

   Methode = Fähigkeit
