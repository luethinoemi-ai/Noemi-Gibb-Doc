Gültigkeitsbereiche
===================

private
~~~~~~~

Nur innerhalb derselben Klasse sichtbar.

protected
~~~~~~~~~

Sichtbar:

- in derselben Klasse
- in Unterklassen
- im selben Package

public
~~~~~~

Überall sichtbar.

Übersicht
~~~~~~~~~

.. code-block:: text

   private   -> nur Klasse

   protected -> Klasse + Vererbung

   public    -> überall

Vergleich
~~~~~~~~~

.. code-block:: text

   private
   -> nur in derselben Klasse

   protected
   -> Klasse + Unterklassen + gleiches Package

   public
   -> überall sichtbar

Merksatz
~~~~~~~~

.. tip::

   private = am stärksten geschützt

   protected = teilweise freigegeben

   public = überall zugänglich

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   private = eingeschränkt

   protected = erweitert

   public = überall sichtbar
