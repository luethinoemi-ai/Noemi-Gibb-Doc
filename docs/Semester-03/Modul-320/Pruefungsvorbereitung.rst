Prüfungsvorbereitung
====================

Wichtige Begriffe
~~~~~~~~~~~~~~~~~

Klasse
^^^^^^

Bauplan für Objekte.

Objekt
^^^^^^

Instanz einer Klasse.

Attribut
^^^^^^^^^

Information eines Objekts.

Methode
^^^^^^^

Fähigkeit eines Objekts.

Konstruktor
^^^^^^^^^^^

Setzt Startwerte beim Erstellen eines Objekts.

Getter
^^^^^^

Liest Werte aus einem Objekt.

Setter
^^^^^^

Schreibt Werte in ein Objekt.

Javadoc
^^^^^^^

Erzeugt Dokumentation aus Kommentaren.

toString()
^^^^^^^^^^

Gibt ein Objekt als lesbaren Text zurück.

try / catch
^^^^^^^^^^^

Fehler abfangen.

throw
^^^^^

Fehler auslösen.

Wichtige Merksätze
~~~~~~~~~~~~~~~~~~

.. tip::

   Klasse = Bauplan

   Objekt = Instanz

   Attribut = Eigenschaft

   Methode = Fähigkeit

   Getter = Lesen

   Setter = Schreiben

   Konstruktor = Startwerte
