Attribute einer Klasse
======================

Was sind Attribute?
~~~~~~~~~~~~~~~~~~~

Attribute speichern Informationen über ein Objekt.

.. important::

   Attribut = Eigenschaft eines Objekts

Beispiel
~~~~~~~~

.. code-block:: text

   Auto

   Farbe
   Marke
   Leistung

Diese Informationen sind Attribute.

Datentypen
~~~~~~~~~~

Im Modul werden folgende Datentypen verwendet:

String
^^^^^^

Text

Beispiel:

.. code-block:: java

   String liquidName;

int
^^^

Ganze Zahl

Beispiel:

.. code-block:: java

   int height;

double
^^^^^^

Kommazahl

Beispiel:

.. code-block:: java

   double density;

Beispiel aus dem Modul
~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: java

   private String liquidName;
   protected int height;
   protected int diameter;
   protected double density;

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Attribute speichern Daten eines Objekts.

   String = Text

   int = ganze Zahl

   double = Kommazahl
