Testen
======

Warum testen?
~~~~~~~~~~~~~

Tests prüfen, ob ein Programm korrekt funktioniert.

JUnit
~~~~~

Im Modul wird JUnit verwendet.

Beispiel:

.. code-block:: java

   assertEquals(120,
      tank.getWidth());

assertEquals
~~~~~~~~~~~~

Prüft, ob zwei Werte gleich sind.

assertThrows
~~~~~~~~~~~~

Prüft, ob ein Fehler ausgelöst wird.

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Tests helfen dabei, Fehler früh zu erkennen.
