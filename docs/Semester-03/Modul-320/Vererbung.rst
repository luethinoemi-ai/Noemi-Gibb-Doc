Vererbung
==========

Was ist Vererbung?
~~~~~~~~~~~~~~~~~~

Vererbung bedeutet, dass eine Klasse Eigenschaften und Methoden einer anderen Klasse übernehmen kann.

Grundidee
~~~~~~~~~

Statt denselben Code mehrfach zu schreiben, kann bestehender Code wiederverwendet werden.

Beispiel aus dem Alltag
~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: text

   Fahrzeug
      ↓

   Auto

   Motorrad

Auto und Motorrad übernehmen Eigenschaften eines Fahrzeugs.

Java
~~~~

Bei der Vererbung erhält eine Klasse Fähigkeiten einer anderen Klasse.

.. note::

   Im Modul wird Vererbung später noch detaillierter behandelt.

Warum Vererbung?
~~~~~~~~~~~~~~~~

Vorteile:

- Wiederverwendbarer Code
- Weniger Duplikate
- Einfachere Erweiterungen

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Vererbung = Übernahme von Eigenschaften und Methoden einer anderen Klasse

   Ziel: Code wiederverwenden
