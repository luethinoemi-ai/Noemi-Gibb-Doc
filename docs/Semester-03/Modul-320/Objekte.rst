Objekte
========

Was ist ein Objekt?
~~~~~~~~~~~~~~~~~~~

Ein Objekt ist eine Instanz einer Klasse.

.. important::

   Objekt = konkretes Exemplar einer Klasse

Beispiel
~~~~~~~~

.. code-block:: text

   Klasse = Auto

   Objekt = Mein roter VW Golf

Objekte erstellen
~~~~~~~~~~~~~~~~~

Mit dem Schlüsselwort:

.. code-block:: java

   new

wird ein Objekt erstellt.

Beispiel:

.. code-block:: java

   BottleCylindrical bottle1 =
      new BottleCylindrical();

Referenz
~~~~~~~~

Das Objekt wird in einer Variablen gespeichert.

Beispiel:

.. code-block:: java

   BottleCylindrical bottle1

bottle1 ist eine Referenz auf das Objekt.

Objekte und Speicher
~~~~~~~~~~~~~~~~~~~~

.. code-block:: text

   Klasse
      ↓
   Objekt
      ↓
   Speicher

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Klasse = Bauplan

   Objekt = Instanz einer Klasse

   new = Objekt erstellen
