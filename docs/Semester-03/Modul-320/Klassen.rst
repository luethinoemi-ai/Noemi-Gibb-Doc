Klassen
========

Was ist eine Klasse?
~~~~~~~~~~~~~~~~~~~~

Eine Klasse ist ein Bauplan für Objekte.

In einer Klasse wird festgelegt:

- Welche Informationen gespeichert werden
- Welche Fähigkeiten vorhanden sind

.. important::

   Klasse = Bauplan

Beispiel
~~~~~~~~

.. code-block:: text

   Klasse = Auto

Die Klasse beschreibt:

- Farbe
- Marke
- Leistung

sowie:

- fahren()
- bremsen()
- tanken()

Beispiel aus dem Modul
~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: java

   public class BottleCylindrical {

   }

Die Klasse beschreibt eine zylindrische Flasche.

Wichtige Regeln
~~~~~~~~~~~~~~~

- Klassennamen werden grossgeschrieben.
- In Java muss der Dateiname gleich heissen wie die Klasse.

Beispiel:

.. code-block:: text

   BottleCylindrical.java

   public class BottleCylindrical

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Eine Klasse ist ein Bauplan.

   Aus Klassen entstehen später Objekte.
