Javadoc
=======

Was ist Javadoc?
~~~~~~~~~~~~~~~~

Javadoc erstellt automatisch Dokumentationen aus Kommentaren.

Wichtige Tags
~~~~~~~~~~~~~

``@author``
   Autor der Klasse

``@version``
   Softwareversion

``@since``
   Seit wann der Code existiert

``@param``
   Beschreibt einen Parameter

``@return``
   Beschreibt den Rückgabewert

Komplettes Beispiel
~~~~~~~~~~~~~~~~~~~

.. code-block:: java

   /**
    * Berechnet den Inhalt einer Flasche
    *
    * @author Noemi Lüthi
    * @version 1.0
    * @since 2026
    */
   public class BottleCylindrical {

   }

Zusammenfassung
~~~~~~~~~~~~~~~

.. important::

   Javadoc erzeugt Dokumentation aus Kommentaren.
