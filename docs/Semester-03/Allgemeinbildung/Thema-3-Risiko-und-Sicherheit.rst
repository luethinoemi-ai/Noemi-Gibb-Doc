Thema 3 - Risiko und Sicherheit
===============================

.. note::

   **Lernziele**

   * Risiken erkennen
   * Versicherungen verstehen
   * Drei-Säulen-System kennen

Risiken
--------

Beispiele:

* Krankheit
* Unfall
* Stress
* Alkohol
* Tabak

Risikomanagement
----------------

#. Risiko erkennen
#. Risiko vermeiden
#. Risiko absichern

Versicherungen
--------------

Haftpflichtversicherung:

Schäden an anderen Personen.

Sachversicherungen:

* Hausrat
* Teilkasko
* Vollkasko

Personenversicherungen:

* AHV
* IV
* EO
* ALV
* Krankenkasse

.. important::

   **Merke**

   Haftpflicht = Schäden an Dritten

Drei-Säulen-System
------------------

1. Säule

AHV

2. Säule

Pensionskasse

3. Säule

Private Vorsorge

.. tip::

   AHV = Existenz sichern

   Pensionskasse = Lebensstandard sichern

Verständnisfragen
-----------------

.. dropdown:: Was bezahlt die Haftpflichtversicherung?

   Schäden an Dritten.

.. dropdown:: Welche Aufgabe hat die AHV?

   Sicherung der Existenz.

.. dropdown:: Welche drei Säulen gibt es?

   AHV, Pensionskasse und private Vorsorge.

Zusammenfassung
---------------

.. note::

   Risiken gehören zum Alltag.
   Versicherungen schützen vor finanziellen Folgen.
   Die Altersvorsorge basiert auf dem Drei-Säulen-System.
