Thema 2 - Geld und Kauf
=======================

.. note::

   **Lernziele**

   * Lohn verstehen
   * Budget kennen
   * Kaufvertrag erklären können

Lohn
----

Bruttolohn:

Lohn vor den Abzügen.

Nettolohn:

Lohn nach den Sozialabzügen.

.. important::

   **Merke**

   Bruttolohn - Sozialabzüge = Nettolohn

Sozialabzüge
------------

* AHV
* IV
* EO
* ALV

Banken
------

Banken übernehmen:

* Kontoführung
* Zahlungsverkehr
* Kreditvergabe

Geldanlagen
-----------

* Sparkonto
* Aktie
* Obligation
* Fonds

.. tip::

   Aktie = Anteil an einer Firma

   Obligation = Darlehen

Budget
------

Ein Budget zeigt:

* Einnahmen
* Ausgaben
* Sparmöglichkeiten

Kaufvertrag
-----------

Ablauf:

#. Anfrage
#. Offerte
#. Bestellung
#. Lieferung
#. Zahlung

Finanzierungsarten
------------------

* Barkauf
* Kreditkauf
* Leasing
* Konsumkredit

.. important::

   **Prüfungswissen**

   Leasing bedeutet nicht Eigentum.

Verständnisfragen
-----------------

.. dropdown:: Unterschied zwischen Brutto- und Nettolohn?

   Bruttolohn vor Abzügen.

   Nettolohn nach Abzügen.

.. dropdown:: Was ist eine Aktie?

   Anteil an einem Unternehmen.

.. dropdown:: Was zeigt ein Budget?

   Einnahmen und Ausgaben.

Zusammenfassung
---------------

.. note::

   Geld kann verdient, ausgegeben und angelegt werden.
   Ein Budget hilft beim Planen.
   Ein Kaufvertrag regelt den Kauf von Waren und Dienstleistungen.
