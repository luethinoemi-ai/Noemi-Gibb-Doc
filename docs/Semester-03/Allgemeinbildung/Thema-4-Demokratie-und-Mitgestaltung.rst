Geschichte der Schweiz
----------------------

* 1291 Bundesbrief
* 1848 Bundesstaat
* 1874 Referendum
* 1891 Initiative
* 1971 Frauenstimmrecht
* 2002 UNO-Beitritt

.. important::

   **Diese Jahreszahlen können geprüft werden.**

Demokratie
----------

Die Schweiz ist eine halbdirekte Demokratie.

Die Bevölkerung kann:

* Abstimmen
* Wählen
* Referenden ergreifen
* Initiativen lancieren

Politische Rechte
-----------------

* Stimmrecht
* Wahlrecht
* Referendum
* Initiative

Referendum
----------

Fakultatives Referendum:

* 50'000 Unterschriften
* 100 Tage

Volksinitiative
---------------

* 100'000 Unterschriften
* 18 Monate

.. important::

   **Prüfungswissen**

   * Referendum = 50'000
   * Initiative = 100'000

Gewaltenteilung
---------------

Legislative
~~~~~~~~~~~

Parlament

Macht Gesetze.

Exekutive
~~~~~~~~~

Bundesrat

Führt Gesetze aus.

Judikative
~~~~~~~~~~

Gerichte

Urteilen.

.. tip::

   Legislative = macht Gesetze

   Exekutive = führt Gesetze aus

   Judikative = urteilt

Zusammenfassung
---------------

.. note::

   Die Schweiz ist eine Demokratie.
   Die Bevölkerung kann politisch mitbestimmen.
   Die Gewaltenteilung verhindert Machtmissbrauch.
